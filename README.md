### 1. 临床患者数据分析报告 (Python + UCI 糖尿病数据集)

**项目描述**：基于 UCL 糖尿病数据集（Pima Indians Diabetes），独立完成全流程数据分析，产出含分析结论与业务建议的 PDF 分析报告。

**核心工作**：
- 完成数据加载与探索、缺失值与异常值清洗。
- 完成描述性统计与分组对比分析。
- 绘制箱线图、热力图等完成数据可视化。
- 产出含分析结论与业务建议的 PDF 分析报告。

**技术栈**：Python (Pandas, NumPy, Matplotlib, Seaborn)


### 2. 中医病历文本标注规范与管理 (Label Studio)

**项目描述**：基于公开中医病历数据，制定病名/症状/药物/剂量等实体及关系类型的标注规则，输出标准化标注规范文档，并完成小批量标注与一致性评估。

**核心工作**：
- 制定病名、症状、药物、剂量等实体及关系类型的标注规则。
- 使用 Label Studio 搭建标注项目，配置标注界面，结合 Jieba 分词实现预标注。
- 组织 2-3 人完成小批量标注，进行质检和一致性评估。

**技术栈**：Label Studio, Jieba, Python 


### 3. 中医科室数据可视化看板 (MySQL + Python)

**项目描述**：独立搭建模拟中医医院数据库，完成多表多维查询与统计分析，提取就诊量、复诊率等业务指标，并构建业务可视化看板。

**核心工作**：
- 独立搭建模拟中医医院数据库，完成患者、就诊、处方等数据表设计与模拟数据导入。
- 运用 JOIN、GROUP BY、窗口函数完成多表多维查询与统计分析。
- 通过 Python 完成指标可视化，结合 Excel 透视表构建业务可视化看板。
- 产出数据库文件、SQL 脚本及看板成果。

**技术栈**：MySQL, Python, Excel
